# Rage Creative Website

Official website for **Rage Creative** — a curated collective of creative specialists delivering integrated brand, design, and content solutions.

## About

Rage Creative is not a traditional agency. We are a curated network of specialist creatives — strategists, designers, videographers, copywriters, and developers — assembled specifically for each client's unique challenge.

> Strategy Before Design.

## Stack

- Pure HTML5 / CSS3 (no frameworks)
- Single-file architecture (`index.html`)
- Fully responsive (mobile-first at 768px breakpoint)

## Sections

1. **Navigation** — Fixed nav with blur backdrop
2. **Hero** — Full-screen with tagline and CTAs
3. **About** — Who we are + brand philosophy
4. **Services** — 6 core service offerings
5. **Work/Portfolio** — Selected client projects
6. **Stats** — Key numbers
7. **Contact** — Email CTA
8. **Footer**
